\textit{¿Cuándo usar?} \texttt{pick\_area}: cuando conoces cuántos puntos de una grilla entera están estrictamente dentro (\(I\)) y sobre el borde (\(B\)) de un polígono de vértices enteros. \texttt{heron}: área de un triángulo conociendo solo sus 3 lados (sin coordenadas). \texttt{es\_triangulo}: verifica la desigualdad triangular antes de usar \texttt{heron}. \textbf{Parámetros:} todos reciben números (longitudes o conteos), no puntos.
\[
\text{Área (Pick)} = I + \frac{B}{2} - 1
\]
