# Cualquier linea despues de un caracter '#' se ignora
# Los titulos de seccion van entre corchetes: [Titulo de la seccion]
# Las subsecciones dentro de una seccion siguen el formato:
#   archivo/dentro/de/code.ext<TAB>Titulo de la subseccion
# (el separador entre el archivo y el titulo debe ser un TAB, no espacios)
#
# El titulo tambien puede ser:
#   "-" (o vacio)   -> el archivo continua la subseccion anterior, sin
#                      ningun encabezado nuevo (util cuando una
#                      subseccion mezcla formulas (.tex) y codigo (.py))
#   "~lo-que-sea"   -> el archivo continua la subseccion anterior, pero
#                      con una etiqueta chica sin numerar (no aparece en
#                      el indice). Util para distinguir funciones dentro
#                      de un mismo grupo de archivos pegados, ej.:
#                      "~orientacion()"
#
# Al final del titulo se puede agregar " :: texto" para mostrar una linea
# "Complejidad: texto" (LaTeX tal cual, ej.: "Dijkstra :: \(O(E \log V)\)").
#
# Los .py muestran, bajo el codigo, un bloque gris con un ejemplo de uso
# sacado del bloque "if __name__ ...": por defecto los primeros assert
# simples (mostrados como "expresion == valor"); o, si el archivo lo
# marca, la region entre "# --- ejemplo ---" y "# --- fin ejemplo ---".
#
# El archivo referenciado puede ser:
#   - un .py  -> se muestra como codigo resaltado (se quita el bloque
#                "if __name__ == '__main__':" automaticamente)
#   - un .tex -> se inserta tal cual (para formulas/texto conceptual)
#
# Todo lo que este despues de [Fin] se ignora (sirve como "borrador" temporal)
